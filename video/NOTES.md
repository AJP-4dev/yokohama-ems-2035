## 3. 1フレームあたりの描画時間（実測、render.mjs の PNG 書き出し込み、1920×1080）
- 第0章（three.js・影つき・全面3D）: 150フレーム 34.1s → **約210ms/フレーム**（起動2秒程度を含む。許容400ms以内）
- 第1章（Canvas2D）: 150フレーム 14.9s → **約85ms/フレーム**（目標200ms以内）
- seek() 内の JS 実行は 2D 章 0.2〜0.7ms、3D 章でも数 ms。時間の大半はスクリーンショット（PNG エンコード）とソフトウェア GL（SwiftShader）。初回の3Dフレームのみシェーダコンパイルで約0.5〜1秒。
- 本番 13,050 フレームの見込み: 2D 約85ms×約9,900 + 3D 約210ms×約3,150 ≒ 25分前後。

## 4. SPEC から変えた点と理由
1. **DURATION 470→435秒**: SPEC の章表の長さの合計は470秒で「≈430秒」と矛盾。中身を保って各章を詰めた（表は§1）。
2. **デザイン方針（統括の追加指示）を SPEC より優先**: 左カラム文字／右グラフの非対称、文字サイズ4段（120/48/28/20）、入場はマスクワイプ・線が走る・伸びるの3種、角丸はチップの6pxのみ、字幕帯は左揃え＋赤い縦線、章レールは1本の罫線＋目盛、問いカード・結論カードは白地・左揃え・罫線。SPEC の「問いの文字がフェード」「字幕中央」「10セグメントの章レール」「チップ14〜20px角丸大」は置き換えた。
3. **第0章**: SPEC の字幕2本と「タイトルが下からスライド」をやめ、統括指示どおり「中区→西区→同心円で境界線が走る→港から波状に押し出し→右上カウンター（字幕なし）→ロックアップ（マスクワイプ＋ルール＋赤い正方形）」。結論カードは置かない（タイトルが結論の役）。
4. **第1章の端点**: 出場の線は 2024年実績（256,481）から 2040年（279,273）まで。人口は 2025→2040。重ねるときは各基準年=100 の指数にして「×が開く」を表現（基準年の違いは画面に注記）。
5. **第3章の「85歳以上は20代の10倍」**: データに20代の区分がなく、15–64歳との比は 25.7/2.8≈9.1。DATA から計算できる「15–64歳の約9倍」に変更（試作版）。都筑の実例も SPEC の「2035年 21.5万×…」ではなく DATA どおり 21.5万（2025）→20.6万（2035）→11,961→14,787→12,391件。
6. **第6章のチップ「都筑・青葉・港北: 人口は減るのに…」**: 港北は2025→2035で人口+3.2%（DATA）のため、「都筑と青葉は人口が −4.3%、−5.2%」に分けた（試作版）。
7. **年齢5区分の色**: SPEC どおり 75–84歳＝赤 #e63946。統括方針の「赤は出場件数と強調だけ」と衝突するが、年齢色は SPEC の固定指定を優先した（要判断）。

## 5. 既知の課題
- `[console] GL Driver Message (OpenGL, Performance, GL_CLOSE_PATH_NV, High): GPU stall due to ReadPixels` が3D章のスクリーンショット時に出る（Chromium/SwiftShader の性能警告で、ページのエラーではない。"will no longer repeat" で数回のみ）。render.mjs が console warning も出力するため表示される。
- 静止検出（`scripts/_still.mjs`、章レールを除いて0.5秒刻み）では、試作の第2〜10章に「チップ・字幕以外が3秒以上止まる」区間が多数あった（例: 第4章後半、第5章後半、第9章後半）。字幕の下端に表示時間の進行線を入れたが、縮小比較では検出に掛からない程度の動き。第2章以降の実装担当は各章で小さな動きを足す必要がある。第0・1章は検出なし。
- 第6章（試作）: 南西部の強調は「白い柱を白い柱で強調」になるため弱い。ラベルとエッジ強調で補っているが、色以外の強調（例: 他区の柱を一時的に低く見せる等）は要検討。
- 第7章(b)（試作）: 2段の柱は赤（運ばなかった）／灰（運んだ）に変更。SPEC の「上＝運んだ、下＝運ばなかった」は維持。
- 開発用スクリプト `scripts/_probe.mjs`（QA）と `scripts/_still.mjs`（静止検出）を追加（成果物ではない）。
