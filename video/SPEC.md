# 動画仕様 — 「地図に聞く」横浜市 救急需要の未来地図 2025→2035

目的: サイト https://ajp-4dev.github.io/yokohama-ems-2035/ で「何をして、何が分かったか」を、**何も知らない人が一発で理解できる**7分前後の無音動画にする。読み手は市役所・消防の職員とその上司。ナレーションなし、音なし。字幕と画面内の注釈だけで伝える。

## 技術契約（必ず守る）
- 成果物は `src/scene.html` 1ファイル（＋ `src/data.js` と `vendor/three.module.js` の読み込みのみ）。**ネットワーク要求ゼロ**。画像・フォントファイルの外部読込禁止。フォントは macOS のシステムフォントを指定（日本語 `"Hiragino Sans"`, 数字 `"Avenir Next","Helvetica Neue"`）。
- 1920×1080、30fps。`window.DURATION`（秒、number）と `async window.seek(t)` を公開。**フレームは t だけの純関数**。`Date.now()` / `requestAnimationFrame` ループ / CSS transition / setTimeout 禁止。`seek(t)` の中で全要素の状態を t から計算して描き、three.js は `renderer.render()` を明示的に呼ぶ。seek は同じ t で何度呼んでも同じ絵。
- three.js は ES Module で `import * as THREE from '../vendor/three.module.js'`。WebGL は `preserveDrawingBuffer:true`。
- レンダ確認: `node scripts/render.mjs --frames 0,300,900,...`（静止画 → `out/frames/`）、下書き `node scripts/render.mjs --scale 0.5 --start 0 --end 300`、本番 `node scripts/render.mjs`（`out/video-only.mp4`、音声なし）。コンソールエラー0であること。
- 1フレームの描画は平均 200ms 以内を目標（2Dは Canvas2D か SVG、three.js は3D地図の章だけ）。

## データ（src/data.js の `DATA`）
- `DATA.wards[i]`: `name`, `pop[year]{c,w,e1,e2,e3}`（0–14/15–64/65–74/75–84/85+、2025〜2040）, `disp[year]`（人口変化のみシナリオの出場件数）, `byAge[year]`, `disp24`, `units`,`unitsDay`, `area`, `nonTr`（不搬送率）, `arrive`（到着分）, `dist`, `types{急病,一般負傷,交通事故,転院搬送,...}`, `dn`（昼夜間比）, `in`,`out`, `fac`（校正係数）, `rings[0]`（経緯度ポリゴン）, `c`（重心）
- `DATA.rates{c,w,e1,e2,e3}`（搬送率）, `DATA.series`（1985〜2024 出場件数）, `DATA.hourly[24]`, `DATA.trend{years, rateGroup[year]{c..e3}, stdRate, growthGroup, growthStd, transport, dispatch}`, `DATA.cityArrive`, `DATA.cityNonTr`, `DATA.dayShare`
- シナリオ倍率: 緩やかな利用増 `×1.0075^(y−2024)`、利用増が続く `×1.015^(y−2024)`、年代別トレンド `byAge[y][g]×(1+growthGroup[g])^(y−2024)` の合計。
- 3D地図の座標変換（サイトと同じ）: `x=(lon−139.585)·cos(35.45°)·100`, `z=−(lat−35.455)·100`。`THREE.Shape`→`ExtrudeGeometry(depth 1)`→`rotateX(−π/2)`、`scale.y` で高さ。**平行投影カメラ**（OrthographicCamera）、床は淡い面＋薄いグリッド。柱の色は指標の値でランプ。

## 美的方向
- サイトと同じ色文法を全編固定: 背景 #f4f6f9、紙 #ffffff、文字 #14213d、淡文字 #5b6b82、**紺 #14213d＝人口**、**赤 #e63946＝出場件数**、**紫 #8e3b8f＝85歳以上**、橙 #f4a259＝昼・65–74歳、緑 #1b998b＝減少・良い方向、青 #3a7bd5＝15–64歳、水色 #9ad0f5＝0–14歳。年齢5区分の色は常に c:#9ad0f5 w:#3a7bd5 e1:#f4a259 e2:#e63946 e3:#8e3b8f。
- 参照イメージ: Apple keynote のデータスライド × NHKの解説グラフィック。白背景、余白を広く、太い数字、細い補助線。派手なパーティクルやグローは使わない。**「伸びる・立ち上がる・切り替わる」の3種の動きだけ**で構成し、動きには必ず意味を持たせる（増える＝伸びる、比較＝左右分割、強調＝他を薄くする）。
- 1か所だけ「見せ場」を作ってよい: 第6章の3D地図（2025｜2035の左右分割から、カメラが寄って北部が赤く染まり、柱が伸びる）。ここは three.js の本気を出す（影・エッジ・滑らかなイージング）。
- イージング: 基本 cubic-out、数字カウンターは ease-out-expo、カメラは ease-in-out。1動作 0.6〜1.2秒。3秒以上同じ画面が静止しないよう、常に何かが微かに動く（カウンター、注釈の点灯、ラインの伸び）。ただし忙しくしない。
- レイアウト: 安全マージン 80px。上端に**章レール**（10章の細い帯、現在章が紺で満ちていく）。下端に**字幕帯**（1行・最大22文字・36px・Hiragino Sans W6・白地に紺文字、薄い影）。注釈は「チップ」（角丸、14〜20px、短文）が最大3つ、順に点灯。
- 字幕と注釈の文体: 「〜です／〜ます」を使わない体言止めと短文。専門語は必ず言い換えを添える（例: 搬送率＝「1年に救急車で運ばれる人の割合」、校正係数＝「人口から計算した件数と実際の件数の差を埋める倍率」、昼間補正＝「通勤で入ってくる人のぶんを足す」）。**なぜその処理をするのか**を1行で言う。

## 動きの語彙（実装の指針）
- 線グラフ: パスを stroke-dasharray で左から描く（0.8〜1.5s）。推計線は実績線が終わってから。
- 棒・帯: scaleY/width を 0→1、cubic-out、0.6s。積み上げは下から順に 0.1s ずつ遅らせる。
- カウンター: ease-out-expo で 1.2s、桁区切りあり。
- 分割画面: 中央から縦のワイプ 0.5s。左右は同じ座標系・同じカメラ。
- 3D: カメラ位置は t の関数（ease-in-out）。柱の高さは `scale.y` を補間。色は HSL 補間。エッジ線は細い紺（opacity 0.3）。
- 問いカード: 白板がスライドイン→大きな「？」→問いの文字がタイプではなくフェード→0.3s 保持→次へ。
- 章レール: 画面上端に 10 セグメント。現在章は進行に合わせて紺で満ちる。
- 字幕: 入れ替えはクロスフェード 0.25s。同時に1行だけ。
- 「飽きさせない」ため、各章の最後に小さな「結論」カード（1文）を0.8秒だけ出してから次章へ。

## やってはいけないこと
- ネットワーク、外部画像、外部フォント、音。
- ナレーション前提の説明。字幕に入らない情報は注釈チップで。
- 仕様にない数字の捏造。データにあるものは `DATA` から計算して表示。
- 文字の重なり・はみ出し。注釈は最大3つ、字幕は1行22文字以内。
- 3秒以上の完全静止。逆に、同時に4つ以上が動く忙しさ。
